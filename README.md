# NeuroModulation

## NeuromodulationSNN

`NeuromodulationSNN/` contains a fixed copy of the reference implementation published by AlKilany et al.

- Original repository: `https://github.com/abdalalkilani/NeuromodulationSNN`

The code is included for reference and reproducibility purposes.  
Modifications for this research are managed within this repository.

Please refer to the original repository and publication for details of the original implementation.
